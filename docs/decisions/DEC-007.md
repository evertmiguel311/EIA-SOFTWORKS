# DEC-007 — GitHub Pages como hosting actual, Hostinger como destino futuro

**Fecha:** 2026-07-17
**Estado:** Vigente

## Contexto

[DEC-001](DEC-001.md) se diseñó pensando en Hostinger (FTP/drag-and-drop, `.htaccess`). En la práctica, el sitio se publicó primero en GitHub Pages (`https://evertmiguel311.github.io/EIA-SOFTWORKS/`, rama `master`, sin CI/CD).

## Decisión

Mantener GitHub Pages como hosting activo mientras Hostinger sigue siendo el destino planeado. `.htaccess` se conserva en el repo aunque **no tiene ningún efecto** en GitHub Pages: Pages sirve vía CDN de Fastly con `Cache-Control: max-age=600` fijo, ignorando el archivo por completo.

## Consecuencias

- Un `git push` no publica al instante: Pages tarda en reconstruir y el CDN puede tardar hasta ~10 min en propagar.
- El cache-busting manual (`?v=`) sigue siendo necesario para CSS/JS; el HTML no tiene forma de cache-bustearse a sí mismo, así que un push reciente puede tardar en verse para todos los visitantes.
- Cuando se migre a Hostinger, `.htaccess` empieza a tener efecto real — debe revisarse en ese momento, no asumir que ya está probado en producción.
