# DEC-001 — Sitio HTML/CSS/JS vanilla, sin build step

**Fecha:** 2026-07-15
**Estado:** Vigente

## Contexto

El sitio es la primera materialización pública de la marca EIA Softworks, en una etapa donde no existe todavía necesidad funcional de login, datos dinámicos ni backend. El destino de hosting es Hostinger (subida por FTP/drag-and-drop) y debe poder abrirse directo con doble clic (`file://`) sin romperse.

## Decisión

Construir el sitio con HTML + CSS + JavaScript vanilla, sin npm, sin framework, sin bundler. Un único `styles.css` seccionado por número, un único `main.js` con patrón IIFE (`window.__BRAND__`) y cada `init()` envuelto en `safe()`. Sin `<script type="module">` con imports relativos. Cache-busting manual con `?v=YYYYMMDD`.

## Consecuencias

- El sitio funciona igual en GitHub Pages, en Hostinger o abierto localmente por `file://`.
- No hay proceso de build que pueda fallar ni dependencias que puedan quedar desactualizadas.
- Cada componente se nombra y estructura de forma semántica clara (ver `CLAUDE.md` §9-10) para que, si en el futuro se justifica migrar (ver [DEC de roadmap en CLAUDE.md §18](../../CLAUDE.md#18-futuras-etapas)), el mapeo a componentes React sea directo.
- No se migra antes de tener una razón funcional real que el HTML estático no pueda resolver.
